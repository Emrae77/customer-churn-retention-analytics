# Sources and attribution

## IBM Telco sample

The underlying customer sample is provided by IBM in [telco-customer-churn-on-icp4d](https://github.com/IBM/telco-customer-churn-on-icp4d). This repository downloads the exact CSV at commit `d5371f5d83a446ad5673cbcca3b814b926491f8a` and verifies its SHA-256. It does not bundle the customer-level data or claim ownership of it.

The IBM source repository declares Apache-2.0 for its code pattern. See the [upstream license](https://github.com/IBM/telco-customer-churn-on-icp4d/blob/d5371f5d83a446ad5673cbcca3b814b926491f8a/LICENSE). This notice does not assign a new license to the external dataset. No IBM training notebook or third-party dashboard image was copied into this project.

## Project visuals and dependencies

The images in `images/` are original figures generated by the included Python scripts. pandas, NumPy and Matplotlib are installed as dependencies rather than vendored. Microsoft SQL Server and Power BI are separate products required for the native SQL/BI workflow; they are not included in this package.
